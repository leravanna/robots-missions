# Robot Mission Control with Fake Api

A ready-to-run, React starter.

## Run

Install Node.js 22.12+ (Node 24 LTS also works), unzip this folder, then open a terminal in it:

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. Internet access is needed for installation and RoboHash images; the fake API itself runs entirely in your browser. If images cannot load, cards still show names and controls. Do not open index.html directly.

```sh
npm run build
npm run preview
npm test
```
